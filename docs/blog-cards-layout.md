# Blog 区块布局方案。

## 结构

**上半部分：4 个精选卡片**
- 展示最近的 4 篇，或者最重要的 4 篇文章（人工可指定"精选"，不一定是最新的）
- 卡片本身简化为"链接卡"：只包含**标题**，点击整卡跳转到对应文章页，不再放摘要、分类标签、日期等信息
- 卡片比现在更小、更轻量（不需要 420px 那么高），4 个依然是 2x2 网格
- 保留原来的轮换背景色，维持视觉节奏感

**下半部分：全部文章目录**
- 复用现在 Contact 区块的深色大框（`.contact-card`，深底浅字风格）
- 放一个"全部文章"目录列表：每行一篇文章的标题（+ 可选日期），点击跳转到对应文章页
- 不需要摘要、分类等额外信息，就是一个简洁的目录索引

## 页面顺序（概念示意）

```
[精选文章 2x2 卡片网格]  ← 4 张小卡片，纯标题链接
[全部文章目录（深色大框）]  ← 列表形式，标题 + 链接
[About]
[Contact]
```
